# Contributing to NGINE

Thank you for your interest in contributing to NGINE! 🚀

## How to Contribute

### Reporting Issues

If you find a bug or have a feature request:

1. **Check existing issues** first to avoid duplicates
2. **Open a new issue** with:
   - Clear title and description
   - Steps to reproduce (for bugs)
   - Expected vs actual behavior
   - Screenshots if applicable
   - Device/OS information if relevant

### Making Changes

1. **Fork the repository**
2. **Create a feature branch** from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes**:
   - Follow existing code style (TypeScript, Expo conventions)
   - Add comments for complex logic
   - Update documentation if needed
4. **Test your changes**:
   - Test on multiple platforms if possible (iOS/Android/Web)
   - Ensure no TypeScript errors
   - Check that existing features still work
5. **Commit with clear messages**:
   ```bash
   git commit -m "Add: feature description"
   ```
6. **Push and open a Pull Request**:
   ```bash
   git push origin feature/your-feature-name
   ```

### Code Style Guidelines

- **TypeScript**: Use type annotations, avoid `any`
- **Components**: Use functional components with hooks
- **Naming**: Use descriptive names, camelCase for variables/functions
- **Formatting**: Let Prettier format on save (if configured)
- **Imports**: Organize imports (React, third-party, local)

### Pull Request Process

1. **Update README.md** if you changed setup/installation steps
2. **Update CHANGELOG.md** (if it exists) with your changes
3. **Ensure all checks pass** (if CI is set up)
4. **Request review** from maintainers
5. **Address feedback** promptly

### Areas for Contribution

We welcome contributions in:

- 🐛 **Bug fixes**
- ✨ **New features** (check roadmap first)
- 📚 **Documentation improvements**
- 🎨 **UI/UX enhancements**
- ⚡ **Performance optimizations**
- 🧪 **Tests and test coverage**
- 🌐 **Internationalization (i18n)**

### Questions?

Open a discussion in Issues or reach out to the maintainers.

**Thank you for helping make NGINE better!** 🙏
