# NGINE Screenshots

This folder contains screenshots of the NGINE app for documentation and marketing purposes.

## Recommended Screenshots

Please add the following screenshots when available:

1. **dashboard.png** - Main dashboard showing active goal, daily check-in buttons, and integrity dots
2. **checkin-flow.png** - Energy level selection and blocker input screen
3. **progress-view.png** - Progress tab showing metrics, integrity dots, and focus areas
4. **recovery-mode.png** - Recovery mode screen with comeback message
5. **gallery.png** - Proof gallery with uploaded photos
6. **onboarding.png** - Onboarding flow screens

## Taking Screenshots

### On Physical Device (Recommended)
1. Open app in Expo Go
2. Navigate to the screen you want to capture
3. Take screenshot (device screenshot shortcut)
4. Transfer to computer and save here with descriptive name

### On Simulator/Emulator
- iOS Simulator: `Device → Screenshot` or `Cmd + S`
- Android Emulator: Use device screenshot tool in toolbar

## Naming Convention

Use descriptive names:
- `dashboard-dark.png`
- `checkin-energy-selection.png`
- `progress-integrity-dots.png`
