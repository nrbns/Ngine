# 🚀 NGINE v0.1 - Foundation (Prototype)

**Goal**: Prove the core idea works

## Features

- ✅ Create 1 resolution
- ✅ Set Minimum Daily Discipline (MDD)
- ✅ Daily check-in (Done/Partial/Not done + Energy 1-5)
- ✅ Simple status tracking (On track/Off track)
- ✅ Local storage (no login required)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open your browser to the URL shown (usually `http://localhost:5173`)

## Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.
