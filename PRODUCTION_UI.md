# 🎯 NGINE Production UI - Gold Standard

## Core Principles (Locked)

### What Perfect UI IS:
- ✅ Calm
- ✅ Honest
- ✅ Intentional
- ✅ Serious
- ✅ Human
- ✅ Trustworthy

### What Perfect UI IS NOT:
- ❌ Fancy gradients
- ❌ Too many charts
- ❌ Random cards
- ❌ "AI looking" screens
- ❌ Fake streaks
- ❌ Confetti
- ❌ Childish gamification

> **The user should feel: "This app understands my life."**

---

## Design System

### Typography
- **Font**: Inter / SF Pro (System default)
- **Large headers** with plenty of spacing
- **Clear hierarchy**: H1 → H2 → H3 → Body → Caption

### Colors
- **Neutral base** (#ffffff, #f9fafb)
- **Status colors** only for meaning (Green/Amber/Red/Blue)
- **No neon**, no gradients abuse
- **Muted palette** for calm feel

### Components
- **Cards only when needed**
- **Flat sections preferred**
- **Minimal animations** (opacity, slide)
- **No decorative elements**

---

## Screen Specifications

### 1. Life Dashboard (Home)

**Layout**: Single vertical narrative (NOT card jungle)

**Structure** (Top → Bottom):

1. **Identity Header**
   - Greeting (Good morning/afternoon/evening)
   - Identity statement ("You are becoming...")
   - Calm typography, no icons, no ads

2. **Life Aims**
   - Compact list with progress bars
   - Muted colors
   - Tap = drill down

3. **Today's Execution**
   - Only actionable items
   - One tap → check-in
   - No distractions

4. **Integrity Meter**
   - Truth indicator
   - North star metric
   - Clear label

5. **Insight**
   - Rules / AI
   - One short truth

6. **Single Native Ad**
   - Very subtle
   - One line only

---

### 2. Profile

**NOT settings.** This is identity.

**Shows**:
- Name / Alias
- Identity statement
- Life focus areas
- Total days committed
- Recovery count (normalized failure)

**No toggles. No clutter.**

---

### 3. Aims

**Life direction UI** - long-term thinking.

Each aim shows:
- Why this aim matters
- Linked resolutions
- Historical integrity trend

---

### 4. Resolution View

**Execution unit** - shows:
- Why this resolution exists
- MDD clearly
- Current state
- Last 7 days reality (simple dots)
- Recovery button (always visible)

**No charts. Charts lie.**

---

### 5. Daily Check-In

**Sacred screen** - design rules:
- White background
- No ads
- No icons
- No scroll
- Three questions. Done.

**Must feel SERIOUS.**

---

### 6. Recovery Mode

**Safe space** - UI tone changes:
- Softer colors
- Short text
- No metrics
- No pressure

**This is why users won't uninstall.**

---

## Key UX Rules

### 1. Identity-First, Not Task-First
User sees *who they are becoming* before *what to do today*.

### 2. Low Cognitive Load
No clutter. One focus per screen.

### 3. Truth Over Dopamine
No fake streaks. No confetti. No childish gamification.

### 4. Continuity
Profile → Aims → Resolutions → Daily reality
Everything connects. Nothing feels isolated.

### 5. Fast
Every action < 3 taps.
